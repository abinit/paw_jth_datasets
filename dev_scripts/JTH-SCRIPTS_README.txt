GENERATION OF JTH TABLES - USER GUIDE  
Marc Torrent – Dec. 2025  

----------------------------------------  
1 -- Generation of Pseudopotentials  
   (in RUN-ATOMPAW)

- Copy the input files into the directories INPUT-LDA, INPUT-PBE.  
  Each input file must be placed in a directory specific to the chemical element (Al, H, ...).  
  Input files may contain keywords to generate XML files, UPF files, or coreWF files.  
- Use the script "run_atp.sh".  
- Modify, at the beginning of the script: the XC functional and the number of grid points.  
  If 2000, no modification is needed.  
  If 500, perform a spline step just before writing the XML pseudopotentials.  
- Run the script.  
- Several directories will be created:  
   > RUN-ATP* directories contain the files generated by atompaw.  
   > PSEUDOS* directories contain the pseudopotentials.  
   > COREWF directories contain the core wavefunction files.  

----------------------------------------  
2 -- Calculation of the Delta Factor  
   (in RUN-TOPAZE)

2.A - RUN ABINIT  
- ABINIT input files must be placed in INPUT, one per chemical element, with the format <element>.in or <element>.abi.  
- Pseudopotentials in XML format must be placed in PSEUDOS, named <element>.GGA_PBE-JTH.  
- The "run_jth.sh" file contains the Slurm submission script for the supercomputer (run with ccc_msub run_jth.sh).  
- The execution produces a RUN directory containing ABINIT outputs for each chemical element, in particular the file <element>.abo.  
- Copy the RUN directory into a directory named RUNxxx[-SP]_yyHa, where xxx is the number of grid points (500 or 2000) and yy is the plane-wave cut-off energy in Ha.  
  Keep only the *.abo file; the other files are not needed.  

2.B - ANALYZE THE FILES  
- Run the script "calc_delta.sh":  
  calc_delta.sh <DIRECTORY_WITH_ABO_FILES>  
  (this directory is the one created above)  
  The script calc_delta.sh uses various files found in the SCRIPTS directory.  
- Two files are produced:  
  *_eos.txt : contains the EOS parameters of the chemical elements.  
  *_delta.txt : contains the delta factors of the chemical elements.  

----------------------------------------  
3 -- Modification of Pseudopotential Files  
   (adding the recommended cut-offs)  

3.A - GGA-PBE FILES  
- Generate the delta factor files for each cut-off using the previous procedure.  
- Use the following values: 10, 12, 15, 17.5, 20, 25, 40.  
- Use the following naming convention: RUNxxx[-SP]_yyHa.  
- Once the seven RUNxxx_yyHa_delta.txt files are obtained, use the script "extract_ecut.py" (edit the script before running).  
- This produces a file RUNxxx[-SP]_ecut.txt that contains the recommended cut-offs for all chemical elements.  
- Use the script "insert_ecut.py" to add a line with the recommended cut-offs into the XML pseudopotential files.  
  From the RUN-ATOMPAW directory, run:  
   insert_ecut.py --ecut-file <name_of_*_ecut.txt>  
                  --pseudo-dir <directory_with_pseudos>  
  The pseudo directory must contain the pseudopotentials directly, without subdirectories, named <element>.LDA_PW-JTH.xml.  

3.B - LDA-PW FILES  
- Use the *_ecut.txt files obtained from GGA-PBE and apply the same procedure.  

----------------------------------------  
4 -- Building the JTH Table for Publication  

4.A - CREATE THE SOURCE DIRECTORY CONTAINING THE TABLE  
The directory must contain the following folders:  
  > An INPUT folder with the ATOMPAW input files used in step 1.  
  > An ATOMICDATA folder with the pseudopotentials obtained at the end of step 3.  
  > Optionally an ATOMICDATA-SP folder with specific alternative pseudopotentials.  
  > Optionally a folder containing the PDF file describing the table (possibly with the LaTeX source used to produce it).  

4.B - REMARK  
One may create a TABLE folder for each functional (GGA-PBE, LDA-PW), and a folder for the standard table, plus one for the LIGHT table (adjusted to 500 points).  

4.C - BUILD THE DIRECTORY FOR THE GITHUB REPOSITORY paw_jth_datasets  
- Use the script "create_table.py".  
- Run the script for each table using the same functional (xx, xx-LIGHT).  
- Use the --erase-dest option for the first table:  
   create_table.py --action create_github_from_table  
                   --root <table_directory_created_in_4A>  
                   --dest <destination_github_directory>  
                   [--erase-dest]  
- Use a temporary GitHub directory, then copy it into the actual git repository.  

4.D - BUILD THE WEBSITE FROM THE GITHUB REPOSITORY  
- Use the script "create_table.py".  
- Run it for each functional (LDA, GGA).  
- Use the --erase-dest option for the first table:  
   create_table.py --action create_html_from_github  
                   --root <github_directory_created_in_4C>  
                   --dest <destination_html_directory>  
                   [--erase-dest]  
- Use a temporary html directory.  
- The resulting table is found under index-table.html.  
  You can then copy this HTML code into the ABINIT website.  
- The website uses pseudopotentials stored on GitHub.  

4.E - BUILD A STANDALONE WEBSITE FROM THE TABLE  
   (This step is not required for the official JTH release)  
- Use the script "create_table.py".  
- Run it for each functional (LDA, GGA) and each table (xx, xx-LIGHT).  
- Use the --erase-dest option for the first table:  
   create_table.py --action create_html_from_table  
                   --root <table_directory_created_in_4A>  
                   --dest <destination_html_directory>  
                   [--erase-dest]
